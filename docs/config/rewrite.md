# 設定項目 (`rewrite`)

## `[rewrite]` HTTPレスポンスの書き換え設定

HTTPレスポンスを書き換えてゲームのプレイ感に影響を与える設定です。

> [!IMPORTANT]
> グラフィックの差し替えや、音声のミュートが主な機能で、これらを使ったからと言ってゲームの進行に影響を与えることはありません。<br>
> これらの設定を更新した後はブラウザのキャッシュをクリアして艦これをリロードしてください。

### 設定項目

| 設定項目        | 型      | デフォルト値 | 説明                                                                                                                                       |
| --------------- | ------- | ------------ | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `dummy_favicon` | boolean | `false`      | `/favicon.ico` がリクエストされたとき、ダミーのfaviconを返す。<br>ブラウザが存在しないURLにアクセスして404 Not Foundになるのが嫌な人向け。 |
| `cache_max_age` | integer | `14400`      | rewrite機能でレスポンスするデータのキャッシュ期間（秒）。                                                                                  |
| `mute_mobile`   | boolean | `false`      | モバイル端末ではゲーム開始時に全ての音声をミュートする。<br>母港画面から音量を変更することでミュートを解除できます。[^1]                   |

設定例: *キャッシュ期間を1時間にする & モバイル端末でのミュートを有効にする*

```toml
[rewrite]
cache_max_age = 3600
mute_mobile = true

[rewrite.force_mobile]
safari = true
firefox = true
# custom_user_agent = "Edg/"  # 任意のUser-Agent文字列を指定する例
```

#### `mute_mobile` について

モバイル端末の判定はUser-Agentヘッダーを見て行います。モバイル端末として判定されるのはUser-Agentに `iPhone`, `iPad`, `Android` の文字列を含む端末です。

が、しかし、DMM Games側でこの条件に当てはまる場合にスマホ用Webサイトが表示され、「ご利用端末に対応していません」となり、艦これをプレイするにはデスクトップ(PC)用Webサイトに切り替えないといけません。

そのため、現状で `mute_mobile` 機能を有効にするには、`[rewrite.force_mobile]` セクションで以下のいずれか（または複数）の設定を行い、特定のUser-Agentをモバイル端末として扱う必要があります。

| 設定項目            | 型      | デフォルト値 | 説明                                                                                           |
| ------------------- | ------- | ------------ | ---------------------------------------------------------------------------------------------- |
| `safari`            | boolean | `false`      | User-Agentに `Safari/` を含み、かつ `Chrome/`, `Edg/` を含まない場合、モバイル端末として扱う。 |
| `firefox`           | boolean | `false`      | User-Agentに `Firefox/` を含む場合、モバイル端末として扱う。                                   |
| `custom_user_agent` | string  | なし         | User-Agentに含む場合、モバイル端末として扱う任意の文字列。例: `"Edg/"` (Microsoft Edge)        |

## `[rewrite.mute_enemy_voice]`

深海棲艦ボイスをミュートする。うるさいボスを黙らせるための設定です。<br>
実際には対象ボイスのMP3ファイルへのリクエストに対して再生時間1秒の無音MP3ファイルを返します。

| 設定項目      | 型        | デフォルト値               | 説明                                                                                                 |
| ------------- | --------- | -------------------------- | ---------------------------------------------------------------------------------------------------- |
| `enabled`     | boolean   | `false`                    | 深海棲艦ボイスのミュートを有効にする。                                                               |
| `ship_ids`    | integer[] | `[1898, 1901, 2059, 2061]` | ミュートする深海棲艦のID[^2]。空の場合は全てが対象になる。<br>デフォルトでは7-4と7-5のボスが対象。   |
| `voice_types` | integer[] | `[30, 40, 41]`             | ミュートするボイス種別。空の場合は全てが対象になる。<br>デフォルトでは被弾・撃沈・浄化ボイスが対象。 |

設定例: *ship_ids, voice_typesはデフォルトと同じ*

```toml
[rewrite.mute_enemy_voice]
enabled = true
ship_ids = [
    1898,  # バタビア沖棲姫
    1901,  # バタビア沖棲姫-壊
    2059,  # ヒ船団棲姫
    2061,  # ヒ船団棲姫-壊
]
voice_types = [
    #10,  # 開幕前
    #20,  # 砲撃
    30,  # 被弾
    40,  # 撃沈
    41,  # 浄化
]
```

## `[[rewrite.replace_ship_graphic]]`

キャラクターグラフィックを差し替える。複数回記述可能。

| 設定項目       | 型      | デフォルト値          | 説明                                                                                                                                                                                          |
| -------------- | ------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `from_ship_id` | integer | なし                  | **[必須]** 差し替え元の艦船ID。                                                                                                                                                               |
| `to_ship_id`   | integer | `from_ship_id` と同じ | 差し替え先の艦船ID。`to_ship_id` と `to_version` の少なくとも一方は指定してください。                                                                                                         |
| `to_version`   | integer | なし                  | 差し替え先のバージョン。未指定の場合は最新版。<br>*差し替え先のバージョン情報がX-Ray Proxyのデータベースに保存され、かつオブジェクトストレージにその画像が保存されている必要があります。*[^3] |
| `full_only`    | boolean | `false`               | 立ち絵のみ差し替える。                                                                                                                                                                        |

設定例1: *レキシントンをサラトガに差し替える*

```toml
[[rewrite.replace_ship_graphic]]
from_ship_id = 966  # Lexington
to_ship_id = 433  # Saratoga

[[rewrite.replace_ship_graphic]]
from_ship_id = 735  # Lexington改
to_ship_id = 438  # Saratoga改
```

設定例2: *秋津洲改の立ち絵を水着modeで固定する*

```toml
[[rewrite.replace_ship_graphic]]
from_ship_id = 450  # 秋津洲改
to_version = 39  # 39: 水着, 40: ノーマル, 41: お正月
full_only = true
```

ほか、`to_ship_id` と `to_version` の両方を指定することで、別の艦娘の期間限定グラフィックで固定するような設定も可能です。

[^1]: ゲーム起動時に呼ばれる `/kcsapi/api_start2/get_option_setting` のレスポンスを書き換えて音量を0にするのでタイトルコールも再生されません。

[^2]: ボイスは最も弱い個体のIDでリクエストされる模様。期間限定海域のボスでは難度に依らず丙/丁難度の個体のIDを指定してください。

[^3]: `[resource]` セクションで `ship_graphic_versioning = true` に設定されている状態で取得した過去の画像データが必要ということです。
